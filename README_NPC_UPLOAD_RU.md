# Как загрузить PNG-персонажей после merge

Этот PR намеренно **не содержит бинарные PNG/JPG/WEBP-файлы**, чтобы кнопка создания PR не падала с ошибкой «Бинарные файлы не поддерживаются».

После merge вручную загрузите PNG-персонажей в папку:

```text
assets/npc_png/
```

Нужные имена файлов:

```text
assets/npc_png/kazuo_sato.png
assets/npc_png/aya_morita.png
assets/npc_png/boss.png
assets/npc_png/hr_worker.png
assets/npc_png/it_worker.png
```

Опциональные дополнительные NPC, если хотите заменить все временные карточки:

```text
assets/npc_png/engineer.png
assets/npc_png/cleaner.png
```

## Что будет, если PNG ещё не загружены

Игра не ломается: каждый NPC остаётся на сцене как вертикальная тёмная standee-карточка человеческого роста с именем, должностью, подставкой, коллизией и зоной взаимодействия.

Когда файл с ожидаемым именем появится в `assets/npc_png/`, Godot автоматически сможет использовать его как текстуру standee при следующем запуске/импорте проекта.
